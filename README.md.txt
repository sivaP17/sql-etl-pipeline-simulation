# SQL ETL Pipeline Simulation

## 📌 Project Overview
This project simulates an ETL (Extract, Transform, Load) pipeline using SQLite and SQL. It processes raw sales data, cleans it, and loads it into a structured production table. Audit logs and triggers are used to track data insertion.

## 🛠 Tools Used
- SQLite
- DB Browser for SQLite
- SQL (DDL, DML, Triggers, Constraints)
- CSV files

## 📂 Files Included
- `sales_data.csv` – Sample raw data file
- `etl_queries.sql` – SQL script for table creation, transformation, and logging
- `ETL_Project.db` – SQLite database file
- `SQL_ETL_Project_Report.pdf` – Final 2-page report

## 🚀 Key Features
- Data cleaning (removes NULLs, duplicates)
- Production table with constraints
- Audit log table to track inserts
- Trigger to automate logging

## 📊 Outcome
A clean and practical demonstration of SQL-based ETL pipeline simulation. Useful for interview discussions and backend database training.
